# v0.1.8 変更点（2026-11-26）

- Windows配置のみ変更。4段目4列目は空欄、5段目は基準LED、架台方位、天の川、昼光、夜天光、モニター、空欄、RESET。MIDI ID・種類は不変。
- UdonSharpは Git と v0.1.7 ZIP の同一ファイルを基準。SeMacroButton の割り当てを既存 CenterConsoleController.MacroObjects() の Button.onClick から Editor で収集。直接同じ GameObject に1個だけ付いている場合も収集。SEマクロIDをNagoyaMacroへ直接キャストしない。
- SE割り当てがあるIDは解放時に既存 _Play() を実行。通常マクロ経路は従来どおり。複数のSE対象は登録順に実行し、フィードバックは全対象ONで2、それ以外0。既存同期変数は変更なし。
- MIDIプロトコル・JSON形式・ログフォーマットは変更なし。

## 適用
Windows: Build_Windows.bat で再ビルド。Dataフォルダーは引き継ぐ。
Unity: MidiConsoleController.cs のみ上書き（既存.meta維持）。コンポーネントのメニューから Collect MIDI Macro References を実行し、Sky macro bindings と IDs を確認してScene保存。CenterConsoleController.cs はGitと一致するため上書き不要。
