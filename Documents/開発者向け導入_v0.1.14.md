# NagoyaConsole 2026-11-26 v0.1.14 統合版

## v0.1.14への更新

Windowsを再ビルドし、Unityの既存`MidiConsoleController.cs`を差し替え、Scene保存・コンパイル・ワールド再ビルドを行います。設定タブのラベル取得には更新済みワールドが必要です。詳細は[一般向けREADME](../README.md)。

## v0.1.13までの更新手順

v0.1.12 の INFO を Unity に導入済みの場合は Windows の再ビルドだけで完了します。以下の Unity 手順は v0.1.11 以前から更新する場合に必要です。
1. Windows: Build_Windows.bat で再ビルド。既存 Data フォルダーを引き継ぐ。
2. Unity: `UdonSharp/MidiConsoleController.cs` のみ、既存同名ファイルに上書きする（.meta 維持）。CenterConsoleController.cs、StatusMonitor.cs、AstroInfo.cs、IntegratedSystem.cs は変更不要。
3. 既存 MidiConsoleController の Inspector に追加された `Status Monitor` に、IntegratedSystem の `statusMonitor` と同じ既存 StatusMonitor を登録。コンテキストメニュー `Collect INFO Status Monitor` は Scene 内で候補が1件の場合のみ自動登録する。複数の場合は手動で選ぶ。
4. 既存 Feedback Enabled を ON。既存 Console / Local Input Enabled / VRC Midi Listener / マクロ参照は維持。Scene 保存、UdonSharp コンパイル、ワールド再ビルド。
5. Windows 操作卓タブ上部に INFO が表示され、受信時 ACTIVE。4秒受信なしは OFFLINE。旧ワールドでは従来操作は可能だが INFO は消灯。
