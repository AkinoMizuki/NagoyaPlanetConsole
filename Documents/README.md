## Windows変更履歴（過去の記録）
## v0.1.2
- 右側常時通信モニター、左寄せ、上下/円弧ドラッグ（初動で選択）、正逆灯、基準LEDの停止位置ラベル、RESET追加。
- CC channel 5 (表示6), number 0, value 1: 既存Reset()を呼ぶ。既存Owner/初回同期/ローカル許可条件を維持。
- オフラインRESETは試作用初期値に戻す。オンラインはフィードバックを待つ。
- 基準LEDの既存値 -1,0,1,2 を OFF,1,2,3 と表示。画面上の角度は暫定の -90,-30,30,90 度。Unity実機の角度は変更しない。
- Windowsビルド・Unityコンパイル未実施。

## v0.1.3
- 基準LED: -60/-30/+30/+60度の停止位置を上側の円弧に配置（表示角度のみ）。OFF=-1を維持。
- 架台方位、地平高度回転、風速: 0.49～0.51の中央デッドゾーン（境界を除く、±3.6度未満）で方向灯OFF・赤文字。既存の連続MIDI値は維持。
- RESETを86×36 DIPに縮小、右下寄せ。
- PanelLighting(ID 33): 既存Unityの灰色→赤/緑/橙の補間を操作ラベル・マクロへ反映。方向灯の点灯色も調光。ナビゲーションと通信表示は対象外。
- UdonSharp/通信仕様/JSONは変更なし。Windows実ビルド、描画、実機検証未実施。

## v0.1.4
3ダイヤルの停止範囲 (0.49 < v < 0.51) は MIDI 512 に統一。範囲内の微動は重複送信しない。境界外は量子化後も停止範囲外になるよう補正。初回接続時は状態不明のため最初の操作を送信する。512/1023 は厳密な0.5ではないが既存デッドゾーン内。Windows/Unity実機未検証。

## v0.1.5
設定画面を3区画に整理。接続/切断は全画面ボタン横。右側と通信タブのログ消去は両方の表示バッファをクリアする。VRChatログファイル自体は削除しない。MIDIとフィードバックの状態は個別に赤/緑で表示。既存MIDI/Udon/ダイヤル/調光仕様を維持。Windows実機未検証。
