# v0.1.18

Windows側のみ変更。既存Target 0–39、100–160を維持。位置別Targetは200+操作ID×4+位置番号（0始まり）。既存のSetKnobを経由しCh3で送信。UdonSharp変更なし。実機・Windowsビルド未検証。

## セレクターの位置を鍵盤に割り当てる（v0.1.18）

設定 → 04 外部MIDI / MIDI LEARN で次の3件を個別登録します。

| 割当対象 | 入力方式 | MIDI Learnで押す鍵盤 |
|---|---|---|
| K03 日周4分 マイナス | Note ボタン | ド |
| K03 日周4分 停止 | Note ボタン | レ |
| K03 日周4分 プラス | Note ボタン | ミ |

各行につき「MIDI Learn」→鍵盤→「割当を保存 / 更新」。反転・ソフトテイクオーバーは不要、カーブはリニア、出力なしの場合はフィードバックなし。設定タブを離れて操作してください。VRChatの状態フィードバックが有効であることが必要です。押下で位置を選び、解放では位置を変更しません。CCボタンも利用できます。従来の連続割り当ては別の入力番号で共存できます。2位置、3位置、基準LEDの4位置に対応します。個別位置の照光出力は該当位置で点灯値、それ以外で消灯値を送ります。
