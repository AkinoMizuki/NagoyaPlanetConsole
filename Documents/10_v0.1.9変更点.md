# v0.1.9 変更点 (2026-11-26)

## 操作卓
左右独立の銀色パネル、各四隅にネジ（合計8個）。中央はパネル間の隙間。原点復帰(ID 0)を架台方位の下、南／北(ID 9)と夕／朝(ID 8)を右パネル最下段、RESETを右下に配置。37種類の操作ID・順序はv0.1.8を維持。

## マクロ
上部黒色領域に上昇(ID 5)、下降(ID 6)、停止(ID 7)。左パネルはMacro 1～20、中央に1行分の空き。右パネルはMacro 21～50、6列5段。下パネルは再生、一時停止、サーチ、またたき、Macro 51。銀色3区画の各四隅にネジ（合計12個）。右側通信モニターは全タブで維持。表示サイズはViewboxで追従。設定のボタン編集では移動した3マクロも編集可能。

## Sceneラベル出力
1. UdonSharp/Editor/NagoyaMacroJsonExporter.cs をUnityの既存UdonSharpフォルダー配下のEditorへ追加。
2. Sceneを開き Tools > AkinoMizuki > Nagoya Console > Export Macro JSON を選ぶ。
3. CenterConsoleControllerを指定しプリセット名を入力。Sceneから表示ラベルを取得を押す。
4. 61個のプレビューを確認し macro.json を新規ファイルとして出力。実際のTMP_Textを優先、なければUnity UI Text。未設定は既定ラベル。改行をJSONでエスケープしUTF-8で出力。既存ファイルは上書きしない。
5. Windows版の設定 > Scene JSONを取り込む で出力ファイルを選ぶ。既存プリセットを維持し、名前が重複したら (2) 等を追加。現在の未保存ラベルも既存プリセットに記録してから取り込む。取り込み後は新しいプリセットを選択する。

Sceneそのもののラベル変更やマクロ割り当て変更は行わない。実際のSceneからのJSON生成はUnity上で実行する必要がある。
